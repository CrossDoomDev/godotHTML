# Тихолесье — версия Godot (редактируемая в редакторе)

Нативный перенос исходной HTML5-игры из [MyGameHTML](https://github.com/CrossDoomDev/MyGameHTML) в **Godot 4.7.1**.

Игра хранит карту в сохранённых сценах `TileMapLayer`, здания и декорации — в дереве узлов, а персонажей — в переиспользуемых сценах с `AnimatedSprite2D`. После автоматического импорта всё редактируется через интерфейс Godot.

Проект собирается автоматическим рабочим процессом GitHub Actions. Подробное руководство по редактированию находится в `docs/EDITOR_GUIDE.md` (появится после импорта).
