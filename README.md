# 🌲 Тихолесье — нативная версия на Godot 4.7.1

**Это не HTML в WebView и не перенос рисования через код.** Карта, дома, деревья, мост и персонажи импортированы в настоящие **сцены Godot**, чтобы ими можно было управлять мышью через интерфейс редактора.

Исходник: [MyGameHTML](https://github.com/CrossDoomDev/MyGameHTML) — там сохранена первоначальная веб-версия без изменений.

## Быстрый запуск в Windows

1. Скачайте [ZIP этого репозитория](https://github.com/CrossDoomDev/godotHTML/archive/refs/heads/main.zip) и распакуйте.
2. Откройте **Godot 4.7.1** → **Импортировать** → выберите файл `project.godot` внутри папки.
3. Дождитесь первичного импорта изображений. Нажмите **F5**.
4. Для изменения карты откройте **`scenes/world/village.tscn`** и раскройте дерево сцены.

> Редактор Godot у вас на русском, поэтому ищите в дереве узлы по именам `Ground`, `Roads`, `Water`, `Bridge`, `Actors`.

## Где редактировать карту БЕЗ ПРОГРАММИРОВАНИЯ

| Что нужно поменять | Узел / сцена |
| --- | --- |
| Трава и грунт | `Village/Ground` — TileMapLayer |
| Лесная подстилка, мох | `Village/ForestFloor` — TileMapLayer |
| Дороги | `Village/Roads` — TileMapLayer |
| Вода и её коллизии | `Village/Water` — TileMapLayer |
| Каменный мост | `Village/Bridge` — TileMapLayer |
| Здания | `Village/Actors/Buildings` |
| Деревья | `Village/Actors/Trees` |
| Объекты, фонари, заборы | `Village/Actors/Decorations` |
| NPC | `Village/Actors/NPCs` |
| Враги | `Village/Actors/Enemies` |
| Герой и камера | `scenes/base/player.tscn` |
| Панели и кнопки | `scenes/base/hud.tscn` |
| Кадры анимаций | `resources/animations/*.tres` в SpriteFrames |

Тайловый атлас редактируется в редакторе TileSet; он хранится в `resources/tilesets/village.tres`. Это реальные нарисованные клетки, а не отрисовка через GDScript.

## Управление

- **WASD и стрелки** — движение по физическим коллизиям Godot.
- **Левый щелчок по земле** — поиск пути AStarGrid2D с учётом препятствий.
- **Левый щелчок по NPC, мобу, траве** — подход к цели (вблизи — взаимодействие или атака).
- **E** — взаимодействие с ближайшим NPC или сбор травы.
- **Пробел** — атака ближайшего противника.
- **2** — выпить зелье.
- **B / J** — инвентарь / журнал.
- **Кнопки справа** — те же действия, сохранение и переключение дня/ночи.

## Что перенесено

- Оригинальная карта 40×30 тайлов: трава, лесная подстилка, дорожки, вода, мост, застройка и объекты.
- Все иллюстрации зданий и декораций из HTML, включая исправленные дом старосты и кузницу.
- Персонаж использует только оригинальные 2D-спрайты (`hero.tres`) и `AnimatedSprite2D` — без переключателя на 3D.
- 5 NPC, 5 мобов (включая стража), 6 точек сбора трав.
- Начальное задание старосты, бой и возрождение противников.
- Опыт, уровни, монеты, зелья, древесина, торговля расходниками, сохранение прогресса.
- Нативные коллизии `StaticBody2D`, `CharacterBody2D`, `CollisionShape2D` и TileSet water physics.
- Редактируемые `SpriteFrames`, `AnimatedSprite2D`, `CanvasLayer` и `Control`.

## Что ещё можно дополнить

Это **первый нативный перенос**, а не готовая MMORPG. Пока отсутствуют полноценная сменная экипировка с несколькими слотами, сложные магазины оружия, отдельные интерьеры домов, облачный сервер, импорт старых сохранений из `localStorage`. Некоторые вспомогательные эффекты HTML требуют отдельной полировки. Точки спавна и основную визуальную раскладку можно свободно улучшать в редакторе.

**Важно:** `tools/import_html_art.py` и `tools/build_scenes.gd` используются только для первоначальной подготовки сцен из HTML. После того как начнёте редактировать карту вручную, **не запускайте повторный импорт без резервной копии** — это пересоздаст сцены из HTML.

Подробная инструкция: [docs/EDITOR_GUIDE.md](docs/EDITOR_GUIDE.md). Архитектура: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Проверка

GitHub Actions запускает Godot 4.7.1, собирает исходные сцены и выполняет `tests/smoke.gd`. Система проверяет наличие настоящих TileMapLayer, редактируемых сцен, анимаций, коллизий, пути и основных игровых правил.

Для обычной разработки достаточно Godot — Python и Blender не нужны. Для **переимпорта из HTML** нужны Python 3 + Pillow + Node.js + Git.
