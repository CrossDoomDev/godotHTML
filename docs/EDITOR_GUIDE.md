# 🌲 Как редактировать «Тихолесье» через интерфейс Godot

Этот проект перенесён из HTML в нативный Godot 4.7.1. Важно: **игровая карта уже сохранена в сценах**, во время запуска код не рисует карту и не создаёт деревья заново.

## Как открыть и запустить

1. Откройте Godot 4.7.1 (обычная Windows-версия, не требуется .NET).
2. Нажмите **«Импортировать»** и выберите \`project.godot\` в скачанном репозитории.
3. Подождите, пока Godot импортирует изображения и соберёт превью.
4. Откройте \`scenes/world/village.tscn\` — это **главная редактируемая карта**.
5. Нажмите F6 для запуска открытой сцены или F5 для запуска всей игры через \`scenes/main.tscn\`.

## Нарисовать новую траву, воду или дорожку — без кода

1. В панели **«Сцена»** раскройте \`Village\`.
2. Выберите один из узлов:
   - **Ground** — трава на всей карте.
   - **Roads** — земляные дорожки с бесшовными вариантами краёв.
   - **Water** — вода с настроенной физической коллизией.
   - **Bridge** — каменная кладка перехода.
3. В нижней панели **TileMap** (редактор тайлов) выберите нужный фрагмент из палитры \`resources/tilesets/village.tres\`.
4. Рисуйте кистью. Стирайте ластиком в редакторе тайлов.
5. Сохраните сцену Ctrl+S.

Все клетки настоящие \`TileMapLayer\`, а не самодельная программная имитация. Палитра из \`art/terrain/tileset.png\`: строка 0 — травы; строка 1 — 16 вариантов дороги; строка 2 — вода; строка 3 — мост. Чтобы нарисовать красивую дорожку, используйте вариант без травяной кромки (первый тайл строки 1) для середины, а по краям подберите варианты с зелёной каймой. **Автоматическое переключение по соседям ещё не настроено**, так что крайние тайлы пока выбираются вручную.

## Передвинуть дом, дерево, бочку, NPC или монстра

1. В \`Village\` откройте \`Actors\`.
2. Здания лежат в **Buildings**, деревья в **Trees**, предметы в **Decorations**.
3. Персонажи — в **NPCs**, монстры — в **Enemies**, травы — в **Herbs**.
4. Выделите конкретный объект и переместите его инструментом «Перемещение» прямо на сцене.
5. Для домов и большинства крупных объектов физические границы находятся в дочернем \`StaticBody2D/CollisionShape2D\`.
6. Чтобы добавить копию дерева или NPC, дублируйте существующий узел (\`Ctrl+D\`) или перетащите сцену из \`scenes/base/\`.

**Важно:** после перестановки непроходимых объектов перезапустите игровую сцену. Скрипт \`world.gd\` один раз читает физические препятствия с карты и строит маршрут для мыши на момент запуска.

## Изменить внешний вид и анимации героя

- Откройте \`scenes/base/player.tscn\`.
- Выберите \`AnimatedSprite2D\` и в Inspector откройте ресурс \`SpriteFrames\`.
- Готовые анимации: \`idle_down\`, \`walk_down\`, \`attack_down\` и то же для направлений \`up\`, \`left\`, \`right\`.
- В \`resources/animations/\` есть отдельные атласы для NPC, врагов и **две версии героя** (обычный pixel-art и Blender-рендер 3D).
- Для замены визуального стиля героя в сцене \`player.tscn\` назначьте свойство **Sprite Frames** ресурсом \`hero-3d-atlas.tres\` или \`hero.tres\`. При смене на Blender-атлас размером 128 пикселей настройте \`Scale\` AnimatedSprite2D, чтобы сохранить нужный размер персонажа.

## Изменить поведение

Сначала исследуйте Inspector и сцены, код нужен для правил:
- \`scripts/player.gd\` — управление, движение, атака.
- \`scripts/enemy.gd\` — AI монстров, радиус преследования, перерождение.
- \`scripts/npc.gd\` — параметры NPC.
- \`scripts/game_state.gd\` — монеты, травы, зелья, опыт, сохранение.
- \`scripts/hud.gd\` — связи кнопок с логикой, сами кнопки редактируются в \`scenes/base/hud.tscn\`.

Сохранения Godot лежат в \`user://tiholesye_godot_v1.json\`. HTML \`localStorage\` напрямую не переносится, это отдельный формат.

## Важно об автоимпорте

\`tools/import_html_art.py\` и \`tools/build_scenes.gd\` нужны только для **первоначального переноса из HTML**. После этого **редактируйте сами сцены в Godot**.

Повторный ручной запуск workflow \`Build editable Godot village from HTML\` перегенерирует карту и базовые сцены из HTML-источника, поэтому затрёт ручные изменения таких сцен. Не запускайте его после того, как начнёте разрабатывать свою карту в редакторе, без резервной копии!

## Что пока остаётся прототипом

Сохранены исходная непрерывная деревня с лесом, NPC, монстры, босс, ресурсы, начальный квест, покупка зелья и продажа древесины. Встроенный редактор F2 из браузера заменён настоящим редактором Godot. Расширенная экипировка, полноценное окно магазина кузнеца, сложные интерьерные сцены и онлайн-сервер остаются отдельными этапами. Игровую механику следует проверять в Windows-сборке.
