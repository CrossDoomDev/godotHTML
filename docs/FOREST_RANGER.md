# 🌲 Лесной следопыт — анимации персонажа

Новый двухмерный атлас **уже находится в репозитории**. Он создан из изображения с четырьмя направлениями ходьбы и атаки, которое было согласовано в беседе.

## Где редактировать анимации через интерфейс Godot

1. Откройте `scenes/base/player.tscn`.
2. Выберите `AnimatedSprite2D` → **Sprite Frames** (`resources/animations/hero.tres`).
3. Выберите анимацию, просмотрите кадры и их порядок в нижнем редакторе.

Атлас: `art/characters/forest_ranger.png`, **256×384 пикселя**, 4 столбца × 8 строк с клетками **64×48**. Фон прозрачный. Камера и физический коллайдер героя не изменялись.

| Строка | Анимация |
|---|---|
| 1 | walk_down |
| 2 | walk_up |
| 3 | walk_left (строго сбоку) |
| 4 | walk_right (строго сбоку) |
| 5 | attack_down |
| 6 | attack_up |
| 7 | attack_left |
| 8 | attack_right |

Каждая анимация ходьбы и атаки содержит по **4 кадра**. Idle использует один неподвижный вариант кадра каждого направления, повторённый четыре раза для совместимости с игровыми проверками. Для hit и death сейчас предусмотрены лишь статичные запасные кадры, их полноценную анимацию можно добавить позднее.

`Player/AnimatedSprite2D`: позиция `(0,-32)`, масштаб `(1.5,1.5)`, пиксельная фильтрация «Ближайший». Низ каждого кадра выровнен по ступням.

## Проверка

Регрессионный тест `tests/smoke.gd` проверяет размеры атласа и наличие **не менее 90 непрозрачных пикселей в каждой из 32 ячеек**, чтобы герой не исчез из-за неверно нарезанных кадров. Отдельно проверьте анимацию ног в Windows: художественную правильность нейросетевой походки нельзя гарантировать одними числовыми тестами.
