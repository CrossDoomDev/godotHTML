# 🌲 Новый главный герой — лесной следопыт

Новый пиксельный герой выбран по исходному изображению пользователя. Исходный спрайт-лист имеет **724×2172 пикселя**, прозрачный фон и 4 столбца × 12 строк кадров.

## Установка через интерфейс Godot и Git

1. Скачайте оригинальный PNG «пиксельный спрайт лист лесного следопыта» из беседы.
2. Поместите его в **`art/characters/forest_ranger_source.png`** — именно с таким именем (можно перетащить через Проводник Windows в папку проекта).
3. В Git-плагине Godot сделайте **коммит и Push**, включив только этот файл PNG. Не добавляйте старые .import, если они не нужны.
4. GitHub Actions автоматически запустит [Install uploaded forest ranger sprite sheet](../.github/workflows/install-forest-ranger.yml), выполнит скрипт `tools/install_forest_ranger.py` и сохранит три готовых ресурса:
   - `art/characters/forest_ranger.png` — очищенный прозрачный атлас, 4×12 кадров размером 96×96;
   - `resources/animations/hero.tres` — настоящие `SpriteFrames`, редактируемые через Inspector Godot;
   - `scenes/base/player.tscn` — новая позиция и масштаб визуального узла героя, при этом коллизии и камера не меняются.
5. После успешного Actions нажмите **Извлечь → Получить** в Godot (убедитесь, что нет препятствующих локальных изменений). Закройте/откройте сцену `scenes/base/player.tscn` и запустите F5.

Альтернативно, при установленном Python и Pillow выполните `python tools/install_forest_ranger.py` **локально**, не дожидаясь Actions. Тогда вручную коммитьте созданные три файла.

## Направления, нарезка и анимации

| Строки исходника (от 1) | Анимация | Кадры |
|---|---|---|
| 1–4 | idle_down, idle_up, idle_left, idle_right | по 4 |
| 5–8 | walk_down, walk_up, walk_left, walk_right | по 4 |
| 9–12 | attack_down, attack_up, attack_left, attack_right | по 4 |

Боковые кадры взяты из отдельных строго боковых ракурсов оригинального спрайт-листа, а не зеркалирования трёхчетвертных видов.

Новые спрайты PNG прозрачные, средняя высота на экране порядка 60–65 игровых пикселей. Ступни привязаны к единой позиции внутри каждого кадра. Сам рисунок создан нейросетью, поэтому физическая правильность чередования ног **требует визуальной проверки**. `hit` и `death` временно используют неподвижную позу, потому что в исходнике нет отдельных кадров для этих действий.

## Защита существующего проекта

При установке изменяются **только** ресурс героя, соответствующая PNG и `AnimatedSprite2D` внутри сцены игрока. Непосредственно карта `TileMapLayer`, декорации, персонажи NPC, `addons/godot_git`, квесты и сохранения не затрагиваются. Старый `art/characters/hero.png` остаётся для отката. Если ты уже сам менял Player.tscn, сделай резервную копию перед установкой.
