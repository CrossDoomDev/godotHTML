# 🌲 Лесной следопыт — главный герой «Тихолесья»

Персонаж установлен в основную сцену Godot **непосредственно в репозитории**. Дополнительная ручная загрузка спрайтов и внешние генераторы не нужны.

## Как изменить героя без программирования

1. Откройте `scenes/base/player.tscn` в Godot 4.7.1.
2. Выберите дочерний узел `AnimatedSprite2D`.
3. В Inspector откройте свойство **Sprite Frames**: `resources/animations/hero.tres`.
4. Внизу редактора откройте список 20 анимаций: `idle_down/up/left/right`, `walk_down/up/left/right`, `attack_down/up/left/right`, дополнительные `hit_*` и `death_*` (пока статичные запасные кадры).
5. Кадры берутся из **`art/characters/forest_ranger.png`**, настоящего 2D-спрайт-листа 4×12, шаг клетки 64×64 пикселя, фон прозрачный.
6. Для проверки нажмите F5, пройдитесь WASD и попробуйте бой пробелом.

## Сохранённые ракурсы

| Строка (с единицы) | Анимация | Кадры |
| --- | --- | --- |
| 1–4 | `idle_down`, `idle_up`, `idle_left`, `idle_right` | 4 для каждого направления |
| 5–8 | `walk_down`, `walk_up`, `walk_left`, `walk_right` | 4 для каждого направления |
| 9–12 | `attack_down`, `attack_up`, `attack_left`, `attack_right` | 4 для каждого направления |

Левый и правый кадры показывают **полный боковой профиль**, без зеркалирования фронтального рисунка. Силуэты выровнены по центру и линии ступней, чтобы не прыгать при ходьбе. Однако художественную корректность шага и чередования ног необходимо оценить в запущенной игре — автоматическое центрирование не исправляет анатомию исходной нейросетевой анимации.

Для удара герой разворачивается в сторону ближайшей цели до начала анимации; анимация удара не прерывается циклом ходьбы до окончания кулдауна. Для `hit` и `death` пока стоят одиночные кадры ожидания (оригинальных дополнительных поз не было).
